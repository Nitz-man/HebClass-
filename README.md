# HebClass

HebClass is a Hebrew learning web app for kids. It includes animated character avatars, a Duolingo-style learning path, quizzes, memory cards, crosswords, XP, levels, streak-friendly game UI, generated music, and an admin area.

## Tech Stack

- React 18 frontend
- Node.js / Express backend
- Local JSON data store with optional persistent Render disk
- Render Blueprint deployment via `render.yaml`

## Local Development

Install dependencies:

```bash
cd backend
npm install

cd ../frontend
npm install
```

Run backend:

```bash
cd backend
npm start
```

Run frontend:

```bash
cd frontend
npm start
```

The frontend defaults to `http://localhost:3000` and the backend defaults to `http://localhost:5000`.

## Render Deployment

This repo is prepared for Render Blueprint deploy:

- Web service name: `hebclass`
- Build command: builds React, then installs backend dependencies
- Start command: `cd backend && npm start`
- `JWT_SECRET` is generated by Render
- No persistent disk is configured by default, so the Blueprint can use Render's lowest-cost/free option when available. Add a disk and `DATA_DIR=/var/data` later if you need production progress to persist reliably.

Deploy instructions are in [DEPLOYMENT.md](DEPLOYMENT.md).
